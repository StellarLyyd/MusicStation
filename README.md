# Music Station: A Desktop Music Player
A custom music station that plays MP3 musics. 
Interfaces include knob to control volume, buttons to control functions like Pause, Next, and Replay, and an LCD screen displaying current song name.

## Features

## How it works
- Plays MP3 video in SD card
- When busy goes from 0 to 1, signaling the end of the current song, controls the player to play the next song
- When pause button is pressed, pause the audio
- When pause button is pressed while the player is paused, resume the audio
- When next button is pressed, go to the next song
- Each song number corresponds to a song name, which is displayed on the LCD
- LCD also shows when the audio is paused
